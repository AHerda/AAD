# AAD

This repository contains my work for lecture called *Algorithmic Data Analysis* (pl. Algorytmiczna Analiza Danych)

This consits of practical exercises and implementations in folders named *lab\** and theoretical exercises in folder named *notatatki* (ang. notes).

The practical implementations are written in python and jupyter notebook and are small projects that usualy serve the purpose of demonstrating some idea rather then actualy analysing data. The second described folder contains pdfs and sources written in *Typst* and is divided by lecture blocks but also contains *all.pdf* consisting of combained all other pdfs.
